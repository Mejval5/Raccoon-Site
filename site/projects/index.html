ShadingLanguageX Playground

A demo of Jake Thorn’s shading language

ShadingLanguageX is Jake Thorn’s project: write shaders as code and compile them to MaterialX node graphs. This is a small browser playground for it: a WebAssembly build of the mxslc compiler, with the result previewed live on a sphere, plane or knot.

Edit the MXSL, watch the node graph change, or edit the MaterialX and decompile it back. Share a shader to the gallery, where every entry renders live as you scroll. All the credit for the language goes to Jake.

Voxel Painter

GPU accelerated marching cubes!

A relaxing 3D voxel painting tool: sculpt terrain with a 3D brush, carve it back, undo, then paint it over with colours. Marching cubes and physics both run in compute shaders on the GPU, and your scenes auto-save. Inspired by Oskar Stålberg’s Townscaper.

Windows download on itch.io, source on GitHub.

Procedural level generator

A 2D level generator for Unity, heavily inspired by Spelunky 2. You design rooms as prefabs, nest structures inside them, and it stitches them into levels on Unity’s tilemaps, with borders, backgrounds and object patterns. It even ships with a Spelunky-style movement controller.

GridBlock

Endless, self-repairing block line

A Minecraft challenge: you spawn on one block in an endless void, with a line of blocks running forward forever. Each block is picked from the world seed out of all 1072 in the game, so the line is deterministic, and if you break one, the same block is back next tick.

Pure datapack, no mods, MIT licensed. Source on GitHub.

Raccoon Tweaks

Tweaks for my Pathfinder table

My Foundry VTT module: one module instead of a pile of community ones. It fixes a Tokenizer bug that stacked another frame onto a token every time you opened it, by wrapping a single render call instead of forking the module.

It also adds GM-only AI portraits, generated straight from Foundry through OpenAI’s image API.

Fromage

A programming language, in French

A dynamically typed language with its own bytecode compiler and virtual machine in C, with custom memory management, so it runs anywhere C compiles. For maximum fromage compliance, everything, compiler included, is written in French.

Built while working through Robert Nystrom’s Crafting Interpreters; its tree-walking sibling LoxNet is in C#.
