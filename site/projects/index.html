Chess Turnarment

A round-robin tournament for ridiculous chess bots

An arena in the spirit of Tom7’s Elo World: about 60 weird bots, from chess.com’s 250-rated Martin to a Stockfish whose pieces explode, play every pairing in parallel on all CPU cores. It fits proper Elo with error bars, draws the cross table live, and lets you play against (or as) any bot in the browser.

C#/.NET, built with a swarm of Claude agents working in parallel. A video is on the way.

GridBlock

An infinite, self-repairing line of blocks

A Minecraft challenge: you spawn on a single block in an endless void, with a line of blocks running forward forever. Every block is a pure function of its coordinates and the world seed, so the line is deterministic, and it repairs itself: break one and the same block is back next tick.

1072 blocks from the game’s own registry, no mods, pure datapack. Source on GitHub.
