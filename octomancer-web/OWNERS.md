## Known overlaps and agreed interfaces

- Ragdoll body: Ragdoll owner exposes enter-limp(duration, cause) and exit; Damage model reuses it for incapacitation, impalement and splat.
- Corpses: Damage model exposes onCorpse(x, y, kind); Combat uses it for the juice leak (collectible only with the Siphon Shell).
- NPC aggro: Damage model owns NPC health and aggro for Marlo, Quill, Pip and the pool host. Shop owner owns the shopkeeper and the run-wide shop aggro flag; Damage model calls the shop owner's aggro hook when a shopkeeper is hurt.
- Shells: Damage model owns shell value styles (cowrie, conch, nautilus, pearl). Buried treasure uses those sprites; Materials draws embedded treasure through the treasure owner's per-tile hook.
- Patterns table: Foliage owns foliage rows; Damage model owns hazard and enemy rows; keep rows in separate blocks to ease merges.
- Shop structure: Materials provides the shop frame material (timber, masonry); Shop owner makes it breakable and wires aggro to damage of it.
- Art rule for everyone: natural fantasy (clams, coral, kelp, bone, stone, bioluminescence); no gold, coins, sparkles or glossy mobile UI.
- Before finishing: merge master into your branch, resolve conflicts preserving everyone's work, rerun all tests.

- 2026-10-07, Materials: `level.tiles` (and `world.tileAt`) now hold a MATERIAL ID per cell, still 0 = water and any non-zero = solid (so `!== 0` checks keep working; never test `=== 1` for "solid"). Ids in `play/js/materials.js`: `MAT_WATER 0, MAT_ROCK 1` (main terrain), `MAT_BEDROCK 2` (indestructible), `MAT_BONE 3` (destructible bone-and-coral block), `MAT_TIMBER 4` (sunken-ship wood platform), `MAT_MASONRY 5` (shop frame stone). Room ASCII: `#` rock, `X` bedrock, `B` bone, `=` timber, `M` masonry, `O` pushable block (a prop, not a tile). Shop frame = timber + masonry tiles around the shop room; `world.isBreakable/breakTile` still refuse the shop rect and bedrock (Shop owner: drop the `inShop` guard in world-v2.js to make the frame breakable). Per-tile draw hook for embedded treasure: `setTileDrawHook(fn)` in materials.js; the wall bake calls `fn(ctx, tx, ty, mat, px, py, s)` for every solid non-bedrock tile in the cell after the main-terrain layer (px,py = tile top-left in the cell canvas, s = px per tile). After changing what a tile shows, call `world.touchTile(tx, ty)` so its cell rebakes.
- 2026-10-07, Buried treasure: new `play/js/embed.js` (data + logic) and `play/js/embed-draw.js` (drawing). Finds are spawn records `{type:'embed', x, y, ek, sub}` (ek 1 shell / 2 bomb / 3 item; sub = shell tier 1..4 cowrie, conch, nautilus, pearl, or bomb count, or item code = 1-based index into items.js ITEM_IDS), placed only in main-rock tiles (`tiles[i] === 1`, MAT_ROCK). Live state: `createEmbedded(props)`, a released find is props kind `PK_FIND = 8`. Shell tiers are the table `EMBED_SHELLS` in embed.js (`value`, `art` = which sprite; Damage model: retarget `art`/`value` to your shell styles there). **Per-tile hook for Materials:** `drawTreasureTile(ctx, d, tx, ty, x0, y0, ppu, goggles)` from embed-draw.js (d = `embedded.data` in main.js) draws the find buried in that tile into its screen/cell square and returns VIS_NONE 0 / VIS_SHOWN 1 / VIS_FULL 2. Wire it as `setTileDrawHook((ctx, tx, ty, mat, px, py, s) => { if (mat === MAT_ROCK) drawTreasureTile(ctx, embedded.data, tx, ty, px, py, s, false); })` to bake the always-visible basic shells into the wall cells, and call main.js's live `drawEmbedded(..., { goggles, tileAt, shown: false })` so only the goggles silhouettes and loose finds are drawn live. New carried item id `goggles` (Sea-glass Goggles) sets `octo.seeBuried`; its sprite is `img/v2/item-goggles.webp`, drawn by `drawItemIcon(ctx, 'goggles', ...)` (Combat: the hotbar gets it for free through drawItemIcon; `itemArtVersion()` in items-draw.js bumps when the sprite loads, so a cached icon can redraw).
